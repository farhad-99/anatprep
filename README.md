# anatprep
Anatomical preprocessing snakebids app for TRIDENT (15T) mouse data

```bash
pixi run anatprep /nfs/khan/trainees/ffallahz/ki3/bids /nfs/khan/trainees/ffallahz/ki3/derivatives/test_anatprep participant --filter_mri echo=1 --template_mri DSURQE --cores all
```

